# Правила проекта

## Поставка и границы работ

- Контур `telephone/` — **не наша зона интеграции, не трогать никогда**. Он
  существует для локальных демо; прод-интеграция в нём не нужна.
- Единственная форма поставки модели наружу: **ONNX-артефакт в `models/`
  плюс контракт-документация** (по образцу `models/ANDROID_INTEGRATION.md`,
  `train/DEPLOY.md`). Потребитель — Java-код на стороне заказчика:
  токенизация/декодирование/бизнес-логика живут там.
- Новые модели (экспериментальные архитектуры) доставляются тем же
  способом: ONNX + интеграционная дока; адаптеры под `telephone/` не
  пишутся.
